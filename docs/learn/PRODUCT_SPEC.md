# GridCraft Learn — product specification

Independent educational extension; no official affiliation implied. Upstream: MIT OR Apache-2.0. Target: Russian first, local first, no account required. Teach fluency through seeded drills, then autonomy through open tasks. All numerical grading must use GridCraft commands/calculation and independent expected values. Changed-input probes must use an isolated workbook. AI is optional and never the numerical grader.

Release criteria are the acceptance scenarios in ACCEPTANCE.md. The first milestone is a proved real-engine integration followed by a visible, executable practice loop. Do not claim release readiness before tests and UI verification.
